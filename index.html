THE FRIDAY DECISION

川越 A2 是目前主線

10/30 是紅眼航班抵達日，行程採「老街 → 冰川神社 → KASHIBA」單向移動。池袋保留為下雨、體力不足或突然想逛東京時可切換的備案。

已確定去程 IT216、回程 IT217 已買；星期六晚上住 Dormy Inn 高崎。朋友表示宿舍可讓訪客過夜，但星期五是否實際住下仍待決定。待與朋友討論星期五住宿與會合方式、星期日是否一起住伊香保，以及星期一的行程與住宿。

FRI · OCT 30

星期五，兩條可切換路線

時間是留有通關、轉車及休息緩衝的初稿，並非已訂好的班次。

步調：中等，可隨時縮短行李：川越站置物櫃晚上：鶴ヶ島會合，宿舍住宿待定
  1. 04:00–約 07:30

    羽田入境 → 品川 → 池袋 → 川越

    京急、JR 山手線、東武東上線依序轉乘；不用新幹線。通關時間若拉長，以下景點整體往後順延。

  2. 約 08:00–09:30

    川越站早餐、寄行李

    建議用站內置物櫃；觀光案內所雖可寄物，取件時間只到 16:00，泡湯後可能趕不上。

  3. 10:00–11:30

    藏造老街 → 時之鐘 → 菓子屋橫丁

    先看川越最有代表性的街區，店家想逛才進去，不為名店排隊。

  4. 11:30–13:15

    步行到川越冰川神社，參拜並午餐

    菓子屋橫丁至神社約 1.1 公里、步行約 22 分鐘；若已累，可改搭觀光巴士。午餐找現場不用等的店。

  5. 約 13:15–14:00

    神社 → 伊佐沼入口 → KASHIBA

    從「川越冰川神社」搭東武巴士川越 06 往「伊佐沼入口」，再步行約 15 分鐘。實際發車時間前一晚再核對。

  6. 約 14:00–16:15

    小江戶溫泉 KASHIBA

    泡湯、休息。官網所連的接駁時刻表有 16:15 從溫泉出發、約 16:45 到川越站的車；班次可能調整，現場再次確認。

  7. 傍晚

    川越 → 鶴ヶ島，與朋友會合

    川越站取行李，搭東武東上線到鶴ヶ島站會合。朋友宿舍可讓訪客過夜，但當晚是否住下仍待討論。

想少走路

老街保留時之鐘與菓子屋橫丁即可；神社改搭巴士，溫泉保留。

精神很好

可多逛老街，或把喜多院放入上午；但喜多院與溫泉同日會讓紅眼航班後的行程偏滿。

通關／飛機延誤

保留冰川神社與 KASHIBA；老街縮成時之鐘周邊 30–45 分鐘。

步調：室內活動為主行李：池袋站置物櫃晚上：鶴ヶ島會合，宿舍住宿待定
  1. 04:00–約 07:00

    羽田入境 → 品川 → 池袋

    搭京急到品川，轉 JR 山手線往澀谷、新宿、池袋方向。

  2. 約 07:00–10:00

    池袋站寄行李、早餐及休息

    主要商場約 10:00 才開始營業；這段不要硬排景點。

  3. 10:00–13:00

    Sunshine City

    水族館、展望台、動漫店、購物擇一兩項；場館和店家的營業時間各不相同。

  4. 13:00–16:00

    午餐與彈性散步

    想繼續逛就留在商場；若想坐一下，可到南池袋公園。

  5. 傍晚

    池袋 → 鶴ヶ島

    回池袋站取行李，搭東武東上線往川越方向，確認所搭班次停鶴ヶ島。當晚是否住朋友宿舍待討論。

AIRPORT → KAWAGOE

從羽田出來怎麼搭

同一張 Suica／PASMO 可依序感應搭乘京急、JR、東武；換公司時需依指標出入不同閘門。

01

羽田第 3 航廈 → 品川

入境後找「京急線」指標，搭往品川方向。現行清晨首班 05:26 從羽田 T3 出發、05:46 抵品川；是否趕上取決於落地與通關。

02

品川 → 池袋

轉 JR 山手線往澀谷、新宿、池袋方向，車上約 28 分鐘。池袋是觀光備案，也是在去川越前的轉車站。

03

池袋 → 川越 → 鶴ヶ島

換東武東上線到川越，車程約 30 分鐘。星期五傍晚從川越再坐到鶴ヶ島；上車前確認停靠站。

羽田有直達川越的機場巴士，但目前從第 3 航廈出發的首班為 13:00，與這趟 04:00 抵達的時間不合。全段沒有搭新幹線的必要。
